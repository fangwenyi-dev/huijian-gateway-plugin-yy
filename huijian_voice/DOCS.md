# 慧尖HA语音插件（huijian_voice）

慧尖设备的**本地语音服务器**：识别（STT）、理解（NLU）、执行（HA 意图）、播报（TTS）
全部在局域网内完成，断网可用。零必填配置——安装、启动、配对，三件事。

> 本加载项与「慧尖 LoRa 网关」加载项同仓不同镜像，独立升级，互不影响。
> 依赖（可选增强）：`huijian_ai` HA 集成——**由本加载项自动落盘**，你只需重启一次 HA。

## 它是什么 / 不是什么

- ✅ 局域网语音链路服务器：`huijian_ai` 集成作为消费端连 `ws://<HA>:8000/xiaozhi/v1/…`
  （慧尖卫星固件走「模式 B」= ESPHome API :6053 入 HA，由 HA 语音管线调度；
  matter-broker 形态卫星与小程序也可按端点直连该 WS——三通道对 LAN 开放）
- ✅ HA 意图执行器：`打开客厅的灯` → `POST /api/intent/handle`（huijian_ai 14 意图）
- ❌ 不是公网小智服务器的替代品（公网链路已退役；不提供账号/唤醒云服务）
- ❌ 不自带大模型（LLM 兜底默认关闭，可自配 OpenAI 兼容端点）

## 安装（3 步）

1. 加载项商店添加本仓库 → 安装「慧尖HA语音插件」→ 启动。
2. 首启自动下载语音模型（约 1.3 GB；离线环境见「模型」页的 import 投放口）。
3. **重启一次 HA Core**（加载自动落盘的 huijian_ai 集成）。

固件/小程序端：选择「慧尖HA语音插件加载项」模式（或手填三条端点，管理页「设备配对」
可复制）。局域网免 token 即连；对安全有要求可在设置页开启强制 token。

## 硬件建议

| 平台 | STT | TTS | 内存 |
|---|---|---|---|
| x86 / N100 | RTF≈0.04 | ~1s/句 | ≥2 GB |
| 树莓派 4/5 (aarch64) | 可用 | 可用 | ≥2 GB，建议开「空闲卸载」 |
| 树莓派 3 | 偏慢 | 偏慢 | 不建议 |

## 常见问答

**Q：装了但设备不说话？** 看「状态」页：STT/TTS 未就绪→「模型」页下载；
HA 桥接不可达→检查 HA 重启过没有；「调试」页输入一句看级联轨迹。

**Q：哪些话能听懂？** 开关/调节（亮度·色温·风量·温度·窗帘开合）、窗户（含内倒）、
场景触发词、时间/温度/状态查询。未命中的默认播兜底话术；开 LLM 兜底后可扩展。

**Q：为什么"空调调到26度"不执行？** 缺区域信息时按守卫拒执行（防误伤同型号多空调），
请说「客厅空调调到26度」，或开启 LLM 兜底让它追问。

**Q：音色能换吗？** 设置页 12 个内置音色（默认 小北 sid45），云端 TTS 亦可配。

**Q：完全离线？** 用 `/data/models/import/` 投放模型 + 关闭自动下载即可，无任何出网需求。

## 排障

- **商店里看不到「慧尖HA语音插件」卡片**：先看 Supervisor 日志（系统→诊断）里有无
  `Can't read .../config.yaml`。加载项仓库清单是**整份校验失败即整体静默跳过**
  （无前端报错）——历史上网关加载项就因一行臆造的 schema 语法踩过此坑，
  本仓有钉桩防线；若你添加的是 fork/改版仓库，请以本仓为准。
- **安装一直停在"下载"（Supervisor 日志停在 `Downloading docker image`）**：
  本加载项镜像自 v1.0.1 起走**自有阿里云 Registry 国内直连**
  （`crpi-…cn-shanghai.personal.cr.aliyuncs.com`，单仓多架构自动匹配），
  正常分钟级完成。若仍卡住（如 ACR 服务波动），处置三步：
  ① 等 10~30 分钟后**卸载再重装**（重装即重新拉取）；
  ② 仍慢则「设置→加载项→仓库」移除本仓库重新添加后再装；
  ③ 灾备换源：把仓库文件中 `huijian_voice/config.yaml` 的 image 整行临时改为
  `image: ghcr.io/fangwenyi-dev/{arch}-huijian-voice`（同镜像官方源，
  需你的网络可达 GitHub Registry），保存后检查更新再安装。
- **装好后设备连不上**：确认设备与 HA 主机同网段（本加载项**纯局域网**，
  不提供公网通道）；管理页「配对」区复制带 token 的完整端点给设备。
- **首次说话延迟高**：首启要下载模型（约 450MB，管理页「模型」区看进度）；
  开了「空闲卸载」后每段空闲的首句会多 ~2s 重载时间，省电与响应二选一。

## 限制（诚实清单）

- 「保存为场景 / 创建·修改自动化」语音路径 M1 实装（当前引导到 HA 界面）；
- 播放音乐类意图显式不接管；
- 识别语种：中文 + 中英混说（Paraformer 双语流式），纯英文长句质量一般；
- 唤醒词不在本加载项职责内（固件端本地唤醒）。

## 端口占用

| 端口 | 用途 | 暴露范围 |
|---|---|---|
| 8000 | 小智协议 WS（stt/tts/llm 三通道）+ `GET /discover` 端点自描述 | 局域网（设备连） |
| 8001 | 管理页（Ingress） | 仅 HA/Supervisor（源 IP 白名单） |
| 8002 | 管理 API | 仅容器回环 |

`/discover` 为无凭据 JSON（小程序 mDNS 读不到 TXT 的替代发现面）：只回三条
端点路径、音频参数与是否强制 token，**永不回 token**。
